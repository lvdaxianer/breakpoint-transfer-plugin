# 项目上下文

## 项目概述

breakpoint-transfer-plugin 是一个 JavaScript 插件，用于实现断点续传功能。

## 核心功能

- 大文件分块上传
- 断点续传支持
- 多语言国际化 (i18n)
- 本地存储 (localforage)

## 技术栈

- TypeScript
- Rollup (构建工具)
- ESLint + Prettier (代码规范)
- Husky + Commitlint (Git 规范)

## 发布流程

- 版本号格式: v0.0.1
- 使用 npm publish 发布

## 更新日志

- 格式: Keep a Changelog
- 触发时机: git commit 提交代码时自动更新
